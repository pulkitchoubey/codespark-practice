
# CampusFix

A simple campus issue management application built with React and Vite.

## Features

- Report campus issues.
- Categorise issues by type.
- Assign priority levels.
- View and filter reported issues.
- Mark issues as resolved.
- Track open and resolved issue statistics.
- Persist issues using browser localStorage.

## Technology Stack

- React
- JavaScript
- Vite
- CSS
- Browser localStorage

## Getting Started

Clone the repository:

```bash
git clone https://github.com/pulkitchoubey/codespark-practice.git
```

Enter the project directory:

```bash
cd codespark-practice
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Current Limitations

- Data is stored locally in the browser.
- Issues are not shared between different users.
- No authentication or backend database yet.
